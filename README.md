# Event-Booking-System-CPP
Online Event Booking System developed in C++ using Binary Search Trees (BST), Linked Lists, Queues, and Stacks. The system allows users to view events, book tickets, cancel bookings, and manage event reservations through a console-based interface.
# Online Event Booking System

## Project Overview
An Online Event Booking System developed in C++ to demonstrate the practical implementation of Data Structures.

## Features
- View Events
- Book Tickets
- Cancel Bookings
- View Existing Bookings
- Event Management using BST
- Booking Management using Linked List
- Queue-based Booking Requests
- Stack-based Cancellation Tracking

## Data Structures Used
- Binary Search Tree (BST)
- Linked List
- Queue
- Stack

## Technologies
- C++
- Console UI
- ANSI Escape Sequences
